# 🐕 Sunrise Run

A Mario-style 2D platformer starring Sunrise the dog! Help Sunrise collect treats, bones, and tennis balls while avoiding squirrels. Reach the flag at the end to win!

**[▶️ Play Now](https://nickcoury.github.io/sunrise-run/)**

## Controls

| Key | Action |
|-----|--------|
| ← → or A D | Move left / right |
| ↑ or W or Space | Jump |
| Enter / Click | Start / Restart |

## Gameplay

- **Collect treats** (🦴 bones, 🎾 tennis balls, 🧁 treats) scattered across platforms and floating in the air
- **Avoid squirrels** — they patrol the ground and platforms. Jump on them from above to defeat them!
- **Hit brick blocks** from below to break them for bonus points
- **Reach the flag** at the end of the level to win
- You have **3 lives** — lose one when you hit a squirrel or fall off the map

## Tech

Built with [p5.js](https://p5js.org/) — single HTML file, no build step, no dependencies. Deployed on GitHub Pages.
